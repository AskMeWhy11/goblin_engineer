# Goblin Engineer — памятка для плейтеста

## Что это

Прототип конструктора машин. На каждом уровне есть задача, бюджет и **минимальный риск**:
слишком надёжную машину запустить нельзя. Детали можно удешевлять, но дешёвые чаще отказывают.

## Управление

**Сборка**

| Действие | Клавиша |
|---|---|
| Поставить деталь | левая кнопка мыши по грани |
| Удалить деталь | правая кнопка мыши |
| Повернуть деталь | R (вокруг крепления или вертикали), T (набок) |
| Качество новых деталей | 1 — добротная, 2 — сойдёт, 3 — хлам |
| Свойства детали (качество, клавиши, инверсия) | инструмент «Выбор», затем щелчок по детали |
| Камера | средняя кнопка мыши и колесо, либо W A S D и Q E |
| Запуск | Tab или кнопка «Запуск» |

**Запуск**

| Действие | Клавиша по умолчанию |
|---|---|
| Моторные колёса | стрелки вверх и вниз |
| Рулевой шарнир | стрелки влево и вправо |
| Ракета | Shift |
| Пушка | C |
| Пороховая бочка | B |
| Камера | правая или средняя кнопка мыши, колесо |
| Вернуться в сборку | Tab |
| Повторить с тем же зерном | F5 |
| Пауза | Esc |

Клавиши каждой детали можно переназначить в её свойствах.

## Что полезно знать

- Отказы трёх видов: **выход из строя** (жёлтый), **поломка** (оранжевый), **взрыв** (красный).
  В пороге риска три выхода из строя равны двум поломкам и одному взрыву.
- Деталь изнашивается, только пока нагружена: мотор — пока крутит, ракета — пока горит.
  Блоки, колёса, бочки и свистелки нагружены всегда.
- Удары и встряска ломают дешёвые детали сразу.
- Гибель гоблина-испытателя — это потеря управления, а не поражение.
  Задача засчитывается, даже если до флага докатились одни обломки с креслом.
- Свистелка ничего не делает, зато тяжёлая, дорогая и охотно взрывается.

## Лист наблюдений

Заполняет наблюдатель, по одному листу на игрока.

| Вопрос | Что увидели |
|---|---|
| Менял ли игрок размещение риска между попытками, или нашёл одну уловку и повторял её? | |
| Понял ли без подсказки, почему кнопка запуска заблокирована? | |
| Смеялся над отказами или раздражался? | |
| Хотел ли пройти уровень дешевле после первой победы? | |

Дополнительно стоит записать:

- на каком уровне и на какой попытке игрок бросил или заскучал;
- какие детали он ни разу не поставил;
- были ли подтормаживания или странное поведение физики (что именно делала машина).
